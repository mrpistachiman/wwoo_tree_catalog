# WWOO Tree Catalog

A browsable catalog of every tree in [William Wythers' Overhauled Overworld](https://modrinth.com/project/wwoo)
(WWOO) v3.0.2 for Minecraft 26.3.

**Open it: https://mrpistachiman.github.io/wwoo_tree_catalog/**

## What's in it

- **149 trees**, each with front and side pictures of the tree as grown in game, including the 24 trees WWOO defines
  but never generates.
- **Leaves and wood** each tree is made of, with their share of the tree.
- **Leaf colours as in the tree's home biome** for biome-tinted leaves (oak, jungle, acacia, dark oak, mangrove,
  vines), so a copper beech looks copper and a swamp oak looks olive.
- **Where it grows**: the biomes it generates in and how common it is there, plus biomes where it only appears near
  the border of another biome.
- **A `/place feature` command** to spawn it, with a copy button. All IDs are WWOO's own (`wythers:`) or vanilla
  (`minecraft:`), so they work with only WWOO installed. Trees that WWOO builds from random pieces are marked.

## Finding trees

- Search by name, block or ID.
- Filter by biome, leaves, wood or size (Small, Medium, Large, Giant), or show only trees that are not in worldgen.
- Sort by name, height, width or how common the tree is.
- Click a tree for its details.

The page is a single HTML file with no dependencies, so it also works offline. It follows your system's light/dark
setting.

This is a fan-made reference, not part of WWOO.
